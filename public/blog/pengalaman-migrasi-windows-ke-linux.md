Halo! Pada artikel ini, saya ingin membagikan pengalaman menggunakan Linux, khususnya Ubuntu 26.04.1
LTS dengan kernel 7.0.0-31-generic, sebagai sistem operasi utama (daily driver) untuk kebutuhan
sehari-hari.

### Mengenal Ubuntu

Ubuntu adalah salah satu sistem operasi berbasis Debian yang ramah bagi pemula maupun developer
berpengalaman. Dengan ekosistem open-source yang masif, stabilitas tinggi, serta dukungan package
manager yang lengkap, Ubuntu menawarkan lingkungan kerja yang bersih, cepat, dan bebas dari
bloatware.

Transisi ke Ubuntu memberi saya kebebasan penuh dalam mengelola workflow pengembangan perangkat
lunak, efisiensi sumber daya sistem, serta akses ke komunitas global yang sangat membantu saat
memecahkan masalah teknis.

### Kenapa menggunakan Linux (Ubuntu)?

Sebelumnya, saya adalah pengguna setia Windows dalam jangka waktu yang lama. Windows sangat nyaman,
fungsional, dan ramah untuk sebagian besar orang. Namun, lama-kelamaan saya merasa terganggu dengan
banyaknya bloatware, pembaruan paksa (forced update), serta aplikasi bawaan tidak penting yang
membuat laptop terasa lambat.

Linux menawarkan pendekatan yang berbeda: kebebasan. Ada banyak pilihan distro, mulai dari Arch
Linux yang kompleks hingga Debian yang stabil. Bagi saya, Ubuntu adalah titik tengah yang pas. Tidak
perlu instalasi manual total dari awal, tapi tetap memberikan kendali penuh.

Selain itu, sebagian besar tech stack modern berbasis Debian. Langkah ini tidak hanya meningkatkan
efisiensi kerja, tetapi juga mengubah pola pikir saya dari sekadar konsumen teknologi menjadi
seorang developer yang lebih proaktif.

### Sisi Pro dan Kontra

Kebebasan tentu ada harganya. Di Linux, semua kendali ada di tangan pengguna, yang berarti Anda
harus siap melakukan instalasi manual, mencari solusi di forum, dan meluangkan waktu untuk
beradaptasi.

#### Pro (Kelebihan):

- `Ringan & Bersih:`Tidak ada aplikasi bawaan yang tidak perlu. Anda hanya menginstal apa yang
  benar-benar dipakai.

- `Ramah Pemrograman:`Sangat nyaman untuk coding dengan ekosistem terminal yang seamless.

- `Kustomisasi Tanpa Batas:`Bebas merancang tampilan dan workflow sesuai gaya Anda.

#### Cons (Kekurangan):

- `Produktivitas & Office:`Layanan Microsoft Office tidak bisa digunakan secara natif. Alternatif
  seperti LibreOffice memiliki tampilan antarmuka yang butuh pembiasaan. Saya pribadi menyiasatinya
  dengan menggunakan Google Workspace via browser.

- `Gaming:`Dukungan game di Linux masih terbatas. Walaupun Steam sudah sangat membantu, memainkan
  game lewat third-party tetap memiliki risiko terkena banned.

- `Kompatibilitas Driver:`Sebagian besar driver penting (audio, Wi-Fi, Bluetooth, GPU) sudah
  otomatis terpasang di Ubuntu. Namun, untuk perangkat lunak khusus pabrikan laptop, seperti Nitro
  Sense di Acer. Anda harus mencari alternatif pihak ketiga (misalnya Acer Manager MAX), di mana
  beberapa fitur seperti RGB keyboard terkadang tidak berfungsi optimal.

### Kesimpulan: Apakah Worth It?

Bermigrasi dari Windows ke Linux bukan sekadar mengganti sistem operasi, melainkan mengubah pola
pikir. Anda dipaksa lebih aktif membaca dokumentasi dan meriset masalah.

Linux bukanlah sistem operasi yang cocok untuk semua orang. Ada kompromi yang harus diambil,
terutama terkait aplikasi kantoran dan gaming. Namun, jika Anda mendambakan kebebasan, menyukai
efisiensi, dan fokus pada dunia development, beralih ke Ubuntu bisa jadi keputusan terbaik untuk
meningkatkan produktivitas.
